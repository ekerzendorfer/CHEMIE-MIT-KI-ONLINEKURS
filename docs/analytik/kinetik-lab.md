# KINETIK-LAB – vom Phänomen zum Geschwindigkeitsgesetz

Das **KINETIK-LAB** ist eine browserbasierte Lernumgebung zur photometrischen Reaktionskinetik. Im Mittelpunkt steht nicht das bloße Abspielen einer Simulation, sondern ein vollständiger Erkenntnisweg von einer überraschenden Beobachtung über die Planung und Erprobung einer Messstrategie bis zur Auswertung realer Messdaten.

[**KINETIK-LAB öffnen**](https://ekerzendorfer.github.io/KINETIK_LAB/){ .md-button .md-button--primary }

!!! info "Entwicklungsstand"
    Die derzeit veröffentlichte Version ist ein **Entwicklungsprototyp**. Die didaktische Struktur ist bereits weitgehend ausgearbeitet; die endgültige Kalibrierung des kinetischen Modells und die Realmessdaten werden noch ergänzt.

## Das Beispiel

Ausgangspunkt ist ein einfaches Alltagsszenario aus dem Labor: Eine violette Kristallviolett-Lösung entfärbt sich in einem Becherglas deutlich schneller als erwartet. Erst nach der gemeinsamen Diskussion wird die Zusatzinformation gegeben, dass sich im Gefäß noch **Reste von Natronlauge** befanden.

Aus dieser Beobachtung entwickeln die SchülerInnen schrittweise eine quantitative Fragestellung:

**Wie lässt sich das Verschwinden der Farbe messen – und was kann aus dem zeitlichen Verlauf über die Reaktionskinetik abgeleitet werden?**

## Der Lernweg

Das KINETIK-LAB führt in fünf aufeinander aufbauenden Phasen durch die Untersuchung:

1. **Beobachten und Hypothesen bilden**  
   Eine unerwartete Farbänderung wird beschrieben und zunächst ohne fertige Erklärung diskutiert.

2. **Messung planen**  
   Die SchülerInnen überlegen, wie Farbintensität quantitativ erfasst werden kann, skizzieren einen erwarteten Verlauf und entwickeln einen ersten Messplan.

3. **Virtuell erproben**  
   Wellenlänge, Messintervall und Messdauer werden im virtuellen Photometer getestet. Ungeeignete Strategien dürfen ausdrücklich ausprobiert und verbessert werden.

4. **Real messen**  
   Der entwickelte Plan wird – sofern ein geeignetes Photometer oder Colorimeter vorhanden ist – im realen Experiment umgesetzt. Alternativ können reale Referenzdaten oder ein virtueller Datensatz verwendet werden.

5. **Aus Messdaten Erkenntnisse ableiten**  
   Rohdaten werden geprüft, mit einem Modell verglichen und schrittweise mathematisch ausgewertet. Über linearisierte Darstellungen und die Variation der Hydroxidkonzentration wird schließlich ein kinetisches Modell entwickelt.

!!! tip "Wichtig"
    Das KINETIK-LAB ersetzt weder den realen Versuch noch den vorhergehenden Unterricht zur Reaktionskinetik. Es soll vorhandenes Wissen auf eine reale Messsituation anwenden helfen und den Weg **Messwert → Messkurve → mathematische Darstellung → kinetische Aussage** sichtbar machen.

## Zusammenspiel mit dem SpektralLab

Das KINETIK-LAB ist als **konkrete Forschungssequenz** konzipiert. Das größere **SpektralLab** bleibt dagegen das offenere virtuelle Messgerät. Beide Anwendungen sollen miteinander zusammenspielen: Im KINETIK-LAB wird der Erkenntnisweg strukturiert, im SpektralLab können Messbedingungen systematisch variiert und zusätzliche virtuelle Messreihen erzeugt werden.
