# SÄUREN_LAB – Säuren in Lebensmitteln

!!! info "Vorläufige Kursseite"
    Das SÄUREN_LAB wird derzeit für den Unterricht erprobt. Rückmeldungen aus ersten SchülerInnen-Tests sollen vor weiteren inhaltlichen Erweiterungen in die App einfließen.

Das **SÄUREN_LAB** ist ein browserbasierter Lernweg zur Säure-Base-Titration. Ausgangspunkt ist eine alltägliche Frage:

> **Auf der Essigflasche steht „5 % Säure“. Wie lässt sich diese Angabe experimentell überprüfen?**

Die Anwendung führt schrittweise von einer einfachen pH-Beobachtung über eine selbst erzeugte Titrationskurve bis zur quantitativen Bestimmung des Säuregehalts.

**App starten:** [https://ekerzendorfer.github.io/SAEUREN_LAB/](https://ekerzendorfer.github.io/SAEUREN_LAB/)

## Was ist das Besondere?

Im SÄUREN_LAB wird nicht mit einer fertigen Titrationskurve begonnen. Die Lernenden entwickeln den Mess- und Auswertungsweg schrittweise:

1. pH mit Indikatorpapier abschätzen,
2. mit einer virtuellen pH-Elektrode genauer messen,
3. eine Vermutung über die NaOH-Zugabe formulieren,
4. einzelne Messpunkte aufnehmen,
5. aus der Punktwolke eine Titrationskurve entwickeln,
6. den Äquivalenzbereich und den Äquivalenzpunkt bestimmen,
7. einen geeigneten Indikator auswählen,
8. einen realen Versuch planen,
9. real, per Demonstrationsvideo, mit der **Titrationschallenge** oder im großen **TITRATIONSTOOL** titrieren,
10. aus dem NaOH-Verbrauch den Säuregehalt berechnen und mit dem Etikett vergleichen.

!!! tip "Didaktische Leitidee"
    Der pH-Wert zeigt zunächst nur, **dass** die Probe sauer ist. Erst die Titration ermöglicht eine quantitative Aussage darüber, **wie viel Säure** enthalten ist.

## Zwei virtuelle Zugänge zur eigentlichen Titration

### TITRATIONSTOOL

Das große TITRATIONSTOOL bietet eine speziell vorbereitete Brückenaufgabe für das SÄUREN_LAB. Dort wird nur das benötigte NaOH-Volumen am Äquivalenzpunkt bestimmt; die eigentliche Konzentrationsrechnung erfolgt anschließend wieder im SÄUREN_LAB.

[TITRATIONSTOOL öffnen](https://ekerzendorfer.github.io/TITRATIONSTOOL/)

### Titrationschallenge

Die Titrationschallenge legt den Schwerpunkt stärker auf die **praktische Tätigkeit an der Bürette**:

- Bürettenhahn stufenlos bedienen,
- rechtzeitig von schneller Zugabe auf Tropfenbetrieb wechseln,
- Phenolphthalein-Schlieren beobachten,
- Meniskus ablesen,
- Anfangs- und Endstand unterscheiden,
- den Endpunkt selbst festlegen.

Es gibt drei Schwierigkeitsgrade:

- **Einfach:** Indikator + pH + mitlaufende Punktwolke
- **Mittel:** Indikator + pH
- **Anspruchsvoll:** nur Indikator und Bürette

Im Serienmodus wird eine Probe viermal titriert:

**1 Orientierungstitration + 3 Bestimmungen**

Die Lernenden entscheiden anschließend selbst, welche Werte für den Mittelwert verwendet werden. Erst danach erscheinen Abweichungen, Score und eine kleine statistische Auswertung mit Standardabweichung.

## Reales Experiment bleibt die Referenz

Die virtuelle Umgebung soll das reale Titrieren nicht ersetzen. Sie eignet sich besonders zur Vorbereitung, zur Wiederholung und zur Auswertung. Im Labor kommen zusätzliche praktische Anforderungen hinzu, etwa korrektes Spülen und Füllen der Bürette, Sicherheitsregeln und die reale Wahrnehmung des Indikatorumschlags.

## Technische Hinweise

- läuft direkt im Browser
- keine Installation erforderlich
- Arbeitsprotokoll kann während der Bearbeitung seitlich eingeblendet werden
- Zwischenstand kann lokal im Browser gespeichert und später fortgesetzt werden
- Messdaten können teilweise als CSV exportiert werden
- der lokale Zwischenstand wird nicht an einen Server übertragen
